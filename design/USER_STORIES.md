# Retrium 用户故事重设计（v3 · 全功能覆盖）

> Retrium — 跨平台 DOSBox 老程序（游戏/软件）收藏管理器
> 本版不受现有三页面约束，按"完整产品"重新设计信息架构，覆盖后端全部能力。

## 0. 信息架构（全新）

```
┌────────────┬──────────────────────────────────────┐
│            │  Top Bar（标题 · 刷新 · 主题切换）      │
│  Sidebar   ├──────────────────────────────────────┤
│  ▸ Library │                                      │
│  ▸ Running │              内容区                   │
│  ▸ Settings│                                      │
│  (主题开关) │                                      │
└────────────┴──────────────────────────────────────┘

首次启动 → Setup Wizard（3 步：库目录 → DOSBox → 扫描导入）
详情页为 Library 的下钻页面；编辑/删除/扫描均为对话框。
```

## 1. 用户画像

| 画像 | 描述 |
|------|------|
| **怀旧收藏家** | 几十年 DOS 收藏，想要"书架"式浏览与回忆 |
| **效率型玩家** | 找到 → 启动，路径越短越好 |
| **档案管理者** | 关心元数据完整、多版本管理、备份与防误删 |

## 2. 后端能力 → UI 入口覆盖表（15/15）

| Tauri 命令 | UI 入口 |
|-----------|---------|
| `get_setup_state` / `complete_setup` | Setup Wizard（3 步） |
| `pick_library_directory` / `pick_dosbox_executable` | Wizard / Settings 的 Browse 按钮 |
| `discover_programs` | Library 首次加载 + TopBar 刷新按钮 |
| `add_programs` | Library 工具栏"Add programs" → 扫描对话框（进度+结果） |
| `run_program` | Run 拆分按钮：主键=默认版本，下拉=任意已配置版本 |
| `stop_program` | Detail 页 Stop · Running 页行内 Stop · 卡片快捷停止 |
| `open_program_folder` | Detail/卡片的 Browse（打开所在文件夹） |
| `delete_program` | 卡片菜单/Detail 页 Delete → 确认对话框（明示不可撤销） |
| `archive_program` | Export 按钮（归档备份） |
| `get_program_process` | 卡片 Running 徽标 · Running 页（pid + 版本 + 运行时长） |
| `get_program_summary` | Detail 统计卡（上次运行/累计时长/次数） |
| `get_dosbox_versions` | Run 下拉菜单 · Settings 版本管理 |

## 3. 用户故事（按 Epic）

### E0 · 首次启动 Setup Wizard
- **US-0.1** 三步引导：库目录 → DOSBox → 自动扫描，每步只问一件事，字段带"为什么需要"说明。
- **US-0.2** 🆕 第 3 步实时展示扫描进度与发现结果，完成即进入 Library，第一眼就看到内容。

### E1 · 库总览 Library
- **US-1.1** 关键词即时搜索（名称/开发商/标签），空结果给出"清除筛选"空状态。
- **US-1.2** 分类 Chips（带计数）+ 排序（最近游玩/名称/年份）。
- **US-1.3** 概览条：总数、总时长、运行中、分类数。
- **US-1.4** 🆕 网格/列表双视图切换；列表视图适合大量收藏快速扫读。
- **US-1.5** 🆕 卡片常显信息 + 快捷菜单（运行/打开文件夹/导出/编辑/删除），不用进详情页即可管理。
- **US-1.6** TopBar 刷新按钮重扫库目录。

### E2 · 添加与扫描
- **US-2.1** 🆕 "Add programs"弹出扫描对话框：进度条 + 逐步发现的新程序列表 + 结果 Snackbar。

### E3 · 运行与游玩
- **US-3.1** 一键用默认版本启动；下拉可选任意版本。
- **US-3.2** 运行中：Run→Stop、卡片徽标、Snackbar 反馈。

### E4 · 详情与档案
- **US-4.1** Hero 横幅 + 主操作优先，统计卡（上次运行/累计时长/次数）+ 🆕 近 7 日游玩柱状图。
- **US-4.2** 结构化档案：分类/年份/语言/开发商/发行商/系列/目录/标签，缺失显示"—"。
- **US-4.3** 🆕 元数据编辑对话框：可修改全部字段与标签，保存即时生效。

### E5 · 运行管理 Running（🆕 全新页面）
- **US-5.1** 专用页面列出所有运行中程序：封面、pid、DOSBox 版本、实时运行时长。
- **US-5.2** 单个停止 + 一键 Stop all；空状态引导回库。

### E6 · 设置 Settings（🆕 全新页面）
- **US-6.1** 存储设置：查看/更换库目录。
- **US-6.2** DOSBox 版本管理：列表、设定默认版本、删除、新增版本（名称+路径）。
- **US-6.3** 🆕 外观：深色"终端夜" / 浅色"手册纸"主题即时切换。
- **US-6.4** 关于：版本、开源许可（GPL-3.0）。

### E7 · 安全性
- **US-7.1** 删除必须经对话框确认，标明目录与不可撤销性。
- **US-7.2** 所有异步操作均有 loading 与结果反馈，失败可见。

## 4. 设计基调

- **美学方向**：复古终端 — DOS 琥珀磷光屏；深色主题为默认，浅色为"泛黄手册纸"
- **配色**：暖炭 `#171412` / 纸面 `#1F1B17` / 琥珀 `#FFB300` / 暖白 `#ECE5DA`；浅色模式奶油纸面
- **字体**：IBM Plex Mono（品牌/数字/路径）+ IBM Plex Sans（正文）
- **质感**：封面扫描线叠层、16px 圆角、无霓虹滥用
